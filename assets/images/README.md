# Portfolio image assets

This folder contains local placeholder images for every image slot in the portfolio.

Replace each `.svg` file with your own photo, keeping the same filename, or update the corresponding `src` path in `README.md`:

- `profile-placeholder.svg` — home-page profile image
- `robotics-placeholder.svg` — robotics design image
- `robot-assembly-placeholder.svg` — robotics assembly image
- `robot-development-placeholder.svg` — robotics development/process images

The placeholders are intentionally lightweight SVG files so the site has valid local image paths immediately. JPG, PNG, and WebP files can be used instead; update the extension in the HTML when changing formats.
